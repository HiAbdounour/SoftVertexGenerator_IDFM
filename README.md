Ce repo est créé dans l'unique but de stocker les fichiers XML permettant de générer les plans de ligne pour l'IDFMwiki.\
Le but est de faciliter les opérations de maintenance en cas de mise à jour du [Soft Vertex Generator](https://github.com/HiAbdounour/SoftVertexGenerator).\
*En bonus, le repo fournit des exemples pour les utilisateurs du Soft Vertex Generator.*

En bref :\
**Chaque plan utilisé dans l'IDFMwiki doit avoir son fichier XML présent ici !**
